## Test inputs

Only generated synthetic test identities and menu items were used. The integration test created two menu items:

| Product ID | Test item | Unit price | Quantity | Expected subtotal |
|---|---|---:|---:|---:|
| `6afa7525b2d7419a3968b8ce` | Integrity Test Wrap | ₹12.35 | 2 | ₹24.70 |
| `6afa7525b2d7419a3968b8cf` | Integrity Test Juice | ₹4.50 | 3 | ₹13.50 |
| **Expected total** | | | | **₹38.20** |

Synthetic test student: `TEST008-42892076-c177-40da-8ca8-8b2b1a985bfd`. The POST body included an untrusted student ID and `totalAmount` of ₹0.01 to verify that the server uses the authenticated student and calculates totals from menu prices. Two orders were created: `6afa7526b2d7419a3968b8d0` (cancelled) and `6afa7526b2d7419a3968b8d3` (completed).

## Expected versus observed

| Field/check | Expected | Observed in MongoDB / API |
|---|---|---|
| Product IDs and names | Match selected menu records | Both persisted IDs and names matched |
| Quantities | 2 wraps; 3 juices | 2 and 3 |
| Unit prices | ₹12.35; ₹4.50 from menu | ₹12.35 and ₹4.50 |
| Subtotals | ₹24.70; ₹13.50 | ₹24.70 and ₹13.50 |
| `totalAmount` | ₹38.20, ignoring submitted ₹0.01 | ₹38.20 |
| Student association | Authenticated synthetic test student | `TEST008-42892076-c177-40da-8ca8-8b2b1a985bfd`; client-supplied ID ignored |
| Order visibility | Owner can read; another student cannot | Owner received HTTP 200; other student received HTTP 404 |
| Status update | `Completed` changes status only | Persisted item and total snapshot unchanged |
| Cancellation | `Cancelled` changes status only | Persisted item and total snapshot unchanged |

After verification, the test removed its orders and menu items. A MongoDB query confirmed zero remaining test orders for the synthetic student and zero remaining test menu items.

## Reproduction

Run from `backend/` against the dedicated local test database:

```bash
CPS_TEST_MONGODB_URI=mongodb://127.0.0.1:27017/canteen_preorder_test \
  node --test tests/order-data-integrity.integration.test.js
```

The integration test refuses non-local MongoDB hosts and any database name other than `canteen_preorder_test`. The general `npm test` suite includes this test but skips it unless `CPS_TEST_MONGODB_URI` is set.
