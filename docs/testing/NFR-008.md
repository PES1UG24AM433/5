## Limitations

The test validates order route behavior against in-memory mocked persistence; it does not place an order in a live MongoDB database or inspect a MongoDB Compass/shell record. A local MongoDB listener was not available at `127.0.0.1:27017` during this check. Therefore persistent-storage verification remains outstanding; do not treat this partial result as a full pass.
