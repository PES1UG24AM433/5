## Reproduction

From the repository root, monitor the backend health endpoint and save output to the evidence log:

```bash
mkdir -p docs/testing

while true; do
  ts=$(date -Is)
  result=$(curl --max-time 5 -sS -o /dev/null \
    -w '%{http_code},%{time_total}' \
    http://localhost:5000/api/health 2>&1)
  printf '%s API=%s\n' "$ts" "$result"
  sleep 60
done | tee docs/testing/NFR-002-availability.log
```
