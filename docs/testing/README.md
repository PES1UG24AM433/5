Use this folder for test results, screenshots, performance measurements and code-review evidence.

For every NFR, record:
- Requirement ID and GitHub issue number.
- Environment, test date and test method.
- Actual results against the acceptance criteria.
- Evidence filenames and any related bug.
- Final result: Pass or Fail.
Use test accounts and a test database. Never save real passwords or authentication tokens in your evidence.

For usability testing, record participant outcomes from contemporaneous observations. If results are reconstructed from memory, label them as retrospective and unverified; do not estimate or invent missing task outcomes, help requests, or problems. Keep evaluator walkthroughs separate from participant results.
